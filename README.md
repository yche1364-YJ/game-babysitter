# game-babysitter
Mosquitoes buzz all night; by day it's jackhammers, horns and the neighbor's dog.
In Babysitter, you stop every noise by typing it, from "bzz" to "woof". Keep the baby asleep till dawn and laughing till noon as new pests arrive each day. Zhuyin mode included. Care for the baby for seven days and seven nights to earn your Babysitter Certificate!
